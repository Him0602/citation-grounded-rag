# Citation Grounded RAG

A production-oriented RAG system for document question answering with page-level citations, hybrid search, reranking, streaming responses, and evaluation.

## Features

- PDF document upload
- Page-aware document parsing
- Intelligent chunking
- Embedding generation
- Vector search
- Hybrid search
- Reranking
- Citation-grounded answers
- Page-level citation viewer
- Streaming responses
- RAG evaluation
- FastAPI backend
- PostgreSQL + pgvector
